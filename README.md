# Ask PV — Archived Project Shell

This repository is retained as an early project shell from the Ask PV hackathon build.

The maintained portfolio version, source code, architecture notes, and current documentation live here:

**[dware11/hackathon](https://github.com/dware11/hackathon)**

Ask PV is a student-built prototype exploring campus Q&A, academic preferences, and semester planning for Prairie View A&M University students. It is not an official PVAMU service.
